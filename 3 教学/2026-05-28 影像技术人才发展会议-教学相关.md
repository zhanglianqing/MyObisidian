# 板块一、教学科研系列副高级职称缺口

> 完整逐条表（要求 | 自为/难度 | 需要什么支持）→ [[张帘青-副教授晋升-缺口梳理]]  
> 图例：**已满足** · **可自为（易/中/难）** · **难自为** · **待核实**

## §一 必备基本

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| 师德师风、考核合格、无事故记录（§1.1–1.3） | 待核实 / 可自为 · 易 | 人事核对 |
| 未满 35 岁 ≥1 年辅导员/班主任等（§1.4） | 待核实 | 若无 → 安排班主任/学业导师 |
| 博士学位（§1.5） | **已满足** | — |
| 任中级满 5 年或博士任中级满 2 年（§1.6） | 待核实 | 人事确认申报窗口 |
| **国自然青年及以上 1 项（§1.7②）** | **难自为** | **方向 + 团队 + 预评审** |
| 院级继续教育 ≥10 次/年（§1.8） | 可自为 · 易 | — |
| **教育教学研究论文 ≥1（§1.9）** | 可自为 · 中 | 教改课题/课程建设署名 |

## §二 公共服务（1 + 2/3/4 选一）

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| §2.1 竞赛/大创/互联网+等指导教师 | 待核实 | 认定指导教师身份 |
| §2.2 班主任/学业导师/秘书等 | **难自为** | **安排学业导师等岗位** |
| §2.4 每年 ≥32 学时公共服务 | 可自为 · 易 | — |

## §三 教学（副教授必备 1、2、4）

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| §3.1 独立 ≥2 门（含本科 ≥32 学时/年） | **难自为** | **大框架 + 牵头带课 + 减排班** |
| §3.2 周均学时 ≥4 | **难自为** | 工时置换 |
| §3.4 毕设/实习 ≥2 届 | 可自为 · 中 | 稳定分配指导名额 |

## §四 科研业绩（1/2/3 选一，或 4/5/6/7 选二）

| 要求 | 自为 / 难度 | 需要什么支持 | 备注 |
|------|------------|-------------|------|
| §4.1 A- ≥1 或 B ≥4 | 待核实 | SCU 期刊分级表 | 路径 A |
| §4.2 国自然面上+ / 国家级 ≥60 万等 | **难自为** | 同 §1.7 | 路径 A |
| §4.5 B ≥2 或 D ≥4 且 C ≥2 | 待核实 | 分级表；不够则 targeted 投稿 | **路径 B 候选** |
| §4.7 教学成果/规划教材/精品课等 | 可自为 · 难 | **与李老师框架绑定** | **路径 B 候选** |
| §4.4 / §4.6 | 难自为 | 大项目排名等 | 备选 |

### 会议开场可直说（P0）

2. **教学工时**（§3.1–3.2）— 大框架 + 牵头 + 减排班  
3. **课程建设产出**（§1.9 + §4.7）— 科研方法论 2.0 → [[3 教学/课程建设-big-picture]]  
4. **公共服务岗**（§2.2、§3.4）— 学业导师、毕设名额
