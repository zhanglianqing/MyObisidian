# Current Progress in Real-Time fMRI-Based Neurofeedback（Paret et al., 2019, NeuroImage）

> S1 定稿 · `[@paretCurrentProgressRealtime2019]` · 主稿 Ref **#16**

## One-liner

NeuroImage 2019 方法学综述：系统梳理 rt-fMRI NF 的**实验设计、信号提取、反馈呈现、学习评估**等环节中的**挑战与已达成进展**——适合作为 RTNF Methods / Discussion 里「领域方法学共识与局限」的引用。

## 框架 / 方法要点

- **范围**：real-time fMRI-based NF 全流程——从扫描实时导出、在线预处理、ROI/解码、反馈 UI，到学习曲线与对照条件。
- **核心议题**：
  - **预处理延迟与噪声**：motion、drift、HRF 模糊导致 temporal credit assignment 困难。
  - **反馈指标**：univariate ROI vs multivariate/decoded pattern vs connectivity。
  - **对照与盲法**：sham ROI、yoked feedback、transfer run 等。
  - **学习评估**：run-wise 调节、个体差异、retention / transfer。
- **与 TiCS 2017（Watanabe）关系**：Paret 更偏 **NeuroImage 方法学实操与 pitfalls**；Watanabe 偏 DecNef/FCNef 概念整合。
- **原料说明**：印象笔记仅为 PDF 壳；内化依 bib + 主稿引用语境；细部宜对照 PDF 增补。
