# 投稿征召

> 会议/专栏/特殊征稿等**主动投稿**（非期刊常规投稿包、非审稿）。任务总览 → [[00_SubmissionTrack]]；下一节点 → [[同期项目-下一节点#11 · 投稿征召]]。

## 目录

| 路径 | 用途 |
|------|------|
| `active/` | 进行中征稿 |
| `archive/` | 已提交或已过期 |

每则征稿一个子文件夹；文件夹名含 **截止日期** 或 **征稿简称**，便于检索。

## 与「杂志审稿」区分

| | `10 杂志审稿` | `11 投稿征召`（本目录） |
|--|---------------|-------------------------|
| 方向 | 编辑部邀你审别人稿 | 你向会议/专栏/征文投稿 |
| 典型截止 | 审稿意见 due | 全文/摘要 due |

## 清理

`archive/` 中已提交超过 **12 个月** 且无 revisit 价值 → 可删，保留 `00_SubmissionTrack` 一行摘要。
