# 英语启蒙，快拉听力，过透佩奇要点(2.0版)❗️

> **@庆爸育儿** · [原文](http://xhslink.com/o/7Gmv9RdJ7vo)

## 要点

- **版本升级**：2024年11月发布1.0「过透佩奇要点」，本帖为 **2.0**——补充更具体操作细节；一年内大量孩子通过「五季三段法」实现看后听飞跃、发展裸听能力，部分在佩奇阶段出现口语大爆发。
- **切入节点**：最佳 = 大循环二阶段牛5小段 **或** 常规5中段（小小优趣新版 **Phase15**）；最低门槛 = 大循环二阶段牛5小段 **或** 常规5初期（**Phase14**）；佩奇 **不适合零基础，禁止跨难度**（跨难度 = 低效或无效）。
- **五季三段结构**：第一段 S1～2「看透听透」；第二段 S3「先裸听后回看再复听」；第三段 S4～5「直接裸听（可回看）」。
- **第一段·基础薄弱型（不排斥台词本）**：S1 看1遍动画 + 亲子共读1遍台词本 + 听5遍音频（可降速0.8～0.9x）；S2 看1遍动画 + 听5遍音频（可0.9x或1.0x）。
- **第一段·基础薄弱型（排斥台词本）**：S1 看1遍 → 降速0.8x听2遍 → 回看1遍 → 降速0.8～0.9x听3遍；S2 看1遍 → 听3遍（可0.9x/1.0x）→ 回看1遍 → 常速听2遍。
- **第一段·基础薄弱型（拒绝/不能看动画）**：S1～2 均可亲子共读台词本1遍（喜欢可多遍）+ 降速0.8～0.9x听5遍音频。
- **第一段·基础不错型**：S1 看1遍 + 降速0.8～0.9x听3遍 + 常速听2遍；S2 看1遍 + 常速听5遍。
- **第一段·基础扎实型**：S1～2 均可看1遍动画 + 常速听3遍。
- **第二段 S3**：先裸听（可降速0.8～0.9x）**3～4遍** → 回看动画1遍 → 常速复听音频 **1遍**。
- **第三段 S4～5**：降速0.9x裸听1～2遍 → 常速裸听3～4遍；孩子想回看可回看动画1遍。
- **通用要求**：动画 **去字幕**，台词本 **遮字**。

## 正文

⭕️2024年11月初，庆爸发布了「过透佩奇要点」1.0版，给大家提供了一套高效用佩奇拉听力的方法，该方法将佩奇的前5季分成三段，阶梯操作。
	
第一段：S1-2，看透听透
第二段：S3，先裸听后回看再复听
第三段：S4-5，直接裸听（可回看）
	
👍这一年内，大量孩子通过佩奇的「五季三段法」获益，看后听音频的能力大多实现了质的飞跃，并且能发展出裸听的能力，甚至很多孩子会在佩奇阶段出现口语输出的大爆发（也有孩子会在桥梁阶段出现）。
	
💡之前1.0版本，庆爸对于操作细节描述不够具体，这次2.0版，庆爸稍拓展了下。具体请看文章的图片部分（可左右滑动），以下为概要：
	
✅佩奇最佳切入节点：大循环二阶段牛5小段或常规路径常规5中段，对应小小优趣新版Phase15
✅佩奇最低切入门槛：大循环二阶段牛5小段或常规路径常规5初期，对应小小优趣新版Phase14
	
⚠️庆爸提示：佩奇并不适合零基础，也不建议跨难度。跨难度=低效or无效
	
⭕️第一段：佩奇S1-S2，看透听透
	
🎯情况一：基础薄弱型
1⃣️孩子不排斥过台词本
佩奇S1：看1遍动画，亲子共读1遍台词本，听5遍音频（可降速到0.8-0.9x）
佩奇S2：看1遍动画，听5遍音频（可降速到0.9x，也可恢复到正常语速1.0x）
	
2⃣️孩子排斥过台词本
佩奇S1：看1遍动画，降速（0.8x）听2遍音频，再回看1遍动画，降速（0.8-0.9x）听3遍音频
佩奇S2：看1遍动画，听3遍音频（可降速到0.9x，也可正常1.0x），再回看1遍动画，常速听2遍音频
	
3⃣️孩子拒绝或不能看动画
佩奇S1-S2：都可亲子共读动画台词本1遍（喜欢可多遍），降速（0.8-0.9x）听5遍音频
	
🎯情况二：基础不错型｜看透听透方法：
佩奇S1：看1遍动画，降速（0.8-0.9x）听3遍音频，常速听2遍音频
佩奇S2：看1遍动画，常速听5遍音频
	
🎯情况三：基础扎实型｜看透听透方法：
佩奇S1-S2，都可看1遍动画，常速听3遍音频
	
⭕️第二段：S3先裸听后回看再复听
S3方法：先裸听（可降速到0.8-0.9x）3-4遍，后回看动画1遍，再复听（常速）音频1遍
	
⭕️第三段：S4-5直接裸听（可回看）
S4-S5方法：降速（0.9x）裸听1-2遍，常速裸听3-4遍，若孩子想回看，可回看动画1遍。
	
❗️以上，视觉均需动画去字幕，台词本遮字！
