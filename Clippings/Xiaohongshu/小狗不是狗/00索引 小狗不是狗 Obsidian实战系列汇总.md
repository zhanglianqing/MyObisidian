1. **[[2026-05-20 插件代码粘贴没效果？手把手装好 Obsidian]]** — 关安全模式、装 Templater、开 `Trigger on new file`；或 GitHub 整包替换 `.obsidian`。
2. **[[2026-05-20 Obsidian模板自动归档命名,真的太爽了!]]** — 模板里写目标文件夹名，新建即归档；再加代码自动填标题与递增序号（001、002…）。
3. **[[2026-05-20 把Obsidian日记做成一个「自动任务系统」!]]** — 日记模板：昨日「明日目标」→ 今日目标；未完成项延续；重要/次要任务分区。
4. **[[2026-05-17 每天打开电脑先发呆10分钟？2个模块解决!]]** — **长周期项目管理** + **每日规划** 双模块；与上三步的「日记/模板」互补，管跨周项目上下文。
5. **[[2026-05-20 个人图书馆&影视库,douban图片失效怎么办-]]** — Douban / BookSearch / Media DB + Dataview 展示；豆瓣图失效时用替代源或本地图 + 改查询兼容远程/本地路径。

## 插件一览（系列共用）

| 插件 | 用途 |
|------|------|
| **Templater** | 模板、自动归档路径、日记任务继承、自动标题编号 |
| **Dataview** | 图书馆/影视库列表、阅读状态分组（在读/已读等） |
| **Douban** | 中文书影音元数据（封面链接受限） |
| **BookSearch** | 英文书导入 |
| **Media DB** | 电影/电视剧等（设置模板路径需带 `.md`） |
| **Bases**（可选） | Obsidian 内置库视图；博主更倾向 Dataview 以支持自定义分类同页展示 |
