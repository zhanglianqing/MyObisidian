# 个人图书馆&影视库,douban图片失效怎么办?

> **@小狗不是狗** · [原文](https://www.xiaohongshu.com/discovery/item/69fb21520000000037034da7?source=webshare&xhsshare=pc_web&xsec_token=ABXd-UGIo3ZlAZaiOttgY2eIlABYbPFqpAqdVTLR2USlQ=&xsec_source=pc_share) · 系列索引：[[00索引 小狗不是狗 Obsidian实战系列汇总]]

## 要点

- **目标**：在 Obsidian 内建「藏书馆 + 影视库」，用插件拉元数据、用模板统一字段，再用视图展示阅读/观看状态。
- **核心插件**：Douban、Templater、Dataview、BookSearch（英文书）、Media DB（电影/剧集等）。
- **展示方案一·Dataview**：可按「在读 / 已读」等自定义分类在同一页面分区展示，博主目前主力方案。
- **展示方案二·Bases**：Obsidian 内置库视图；字段多时版面易乱，且难在一页按自定义分类拆分，故博主较少用。
- **豆瓣插件现状**：防爬加强后导入常**封面图失效**（链接打不开）；书影音元数据仍可先豆瓣导入。
- **替代导入**：BookSearch 偏英文书；Media DB 适合电影/电视剧——插件设置里模板路径要写成带 **`.md`** 后缀，否则模板不生效。
- **封面补救**：插件找不到元数据时，可先豆瓣录入再**手动换图**；图存本地则需改 Dataview 查询，**同时支持远程 URL 与本地路径**。
- **代码出处**：兼容本地图的 Dataview 示例与完整搭建步骤在博主博客 / https://jz-quartz.pages.dev/。
- **视频结构**：00:00 搭建思路 → 00:18 Dataview vs Bases → 00:50 豆瓣失效 → 01:29 替代方案 → 02:01 本地图查询修改。

## 内容纪要

### 搭建思路

博主在 Obsidian 中分别维护**图书馆**与**影视库**：下载 Douban、Templater、Dataview 等插件，为书籍/影视各配一套**属性模板**（字段可按个人需求改）。元数据通过插件写入笔记 frontmatter，再用视图聚合展示。

### Dataview 与 Bases 怎么选

- **Dataview**：适合需要「正在读 / 已读完」等**自定义分区**同页展示的场景，也是博主日常用的方案。
- **Bases**：Obsidian 新能力，适合简单库表；信息字段一多会显得拥挤，且不易按自己的分类逻辑排版，故作为备选。

### 豆瓣图片失效与替代

豆瓣加强反爬后，搜索导入的书籍**封面不显示、图片链接失效**，但文本元数据往往仍能导入。应对方式：

1. **BookSearch**：补英文书等资源。
2. **Media DB**：导入电影、剧集等；注意在插件设置里把模板文件路径写成 `xxx.md`。
3. **混合流程**：先用豆瓣写入基础信息，再网上找封面**替换**；若图片下载到 vault 本地，必须调整 Dataview 代码，让查询既读远程 URL 也读本地附件路径（博主在博客提供修改前后对比示例）。

### 与本系列其他帖的关系

依赖 Templater 模板与 Dataview 基础（见 [[2026-05-20 插件代码粘贴没效果？手把手装好 Obsidian]]）；与日记/项目任务系统相对独立，属 **生活向 PKM** 扩展。
