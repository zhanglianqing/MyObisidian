# 插件代码粘贴没效果？手把手装好 Obsidian

> **@小狗不是狗** · [原文](https://www.xiaohongshu.com/discovery/item/69e0bce900000000210120a3?source=webshare&xhsshare=pc_web&xsec_token=AB0ie_vgHlz9VfZ6F-osfCv6_YcYzJSwBhFgnOG655l_s=&xsec_source=pc_share) · 系列索引：[[00索引 小狗不是狗 Obsidian实战系列汇总]]

## 要点

- **背景**：前两期观众把博客代码贴进 Obsidian 后**没效果**；本期演示完整安装与配置，避免「代码对了但环境没就绪」。
- **方法一·手动装插件**：设置里**关闭安全模式** → 社区插件搜索 **Templater** → 安装并启用。
- **Templater 必配**：指定模板存放文件夹（如 `template`）；**务必开启** `Trigger Templater on new file creation`，否则新建文件不会跑模板、代码等同失效。
- **贴代码**：在 vault 建模板 md，从博主博客 https://jz-quartz.pages.dev/ 复制对应视频代码；博主已用代码框重排，避免 Obsidian→博客同步后**乱码/格式破坏**。
- **演示效果**：日记模板可**继承昨日未完成任务**，已完成项不再出现在今日列表。
- **方法二·GitHub 整包**：下载博主 GitHub 仓库里的插件压缩包 → 解压文件夹重命名为 **`.obsidian`** → 替换本地库同名目录 → **关闭并重开库**，常用插件一次性生效，可再自行删减。
- **常见问题**：只复制代码未装 Templater、未开新建触发、安全模式未关，是最多「粘贴无效」的原因。
- **系列位置**：本系列**第 1 步**；后续 [[2026-05-20 Obsidian模板自动归档命名,真的太爽了!]]、[[2026-05-20 把Obsidian日记做成一个「自动任务系统」!]] 都依赖 Templater。

## 内容纪要

### 为什么「复制代码没用」

评论里常见情况是：只把 Templater 脚本贴进笔记，但没有安装插件、没有指定模板目录，或没打开「新建文件时触发 Templater」。本期用空白演示库从零配到能跑通「继承昨日任务」的日记模板。

### 方法一：手动安装 Templater

1. **关闭安全模式**（社区插件前提）。
2. 搜索安装 **Templater**，进入设置：
   - 设置 **Template folder location**（例如 `template`）。
   - 打开 **Trigger Templater on new file creation**（关键开关）。
3. 在模板目录新建 md，从博主博客对应教程复制代码（博主称已修复博客同步导致的乱码，可直接粘贴）。
4. 用该模板新建日记：未完成的昨日任务会**自动延续**到今日，已完成任务不再列出。

### 方法二：GitHub 插件包一键替换

到博主 **GitHub 仓库**下载压缩包，解压后将文件夹改名为 `.obsidian`，覆盖当前 vault 根目录下的 `.obsidian`（可先备份）。重启 Obsidian 后，仓库内预置的常用插件与配置即生效；不需要的插件可自行删除。

### 与后续视频的关系

模板自动归档、日记任务继承、项目追踪等帖子的代码，都建立在**本期的 Templater 环境**之上；若本步未通，后面所有「自动化」都会表现为无效。
