# 每日色卡Vol.23｜春夏必收的氛围感配色 ✅

> **@搞～设计** · [原文](https://www.xiaohongshu.com/discovery/item/6896fb38000000002302c9f9?source=webshare&xhsshare=pc_web&xsec_token=ABVEGx8kitNOk2JtzYSAD-h8Ie0vC-OkGVmyY_SaIQBOI=&xsec_source=pc_share)

## 要点

- **Vol.23 共 9 组配色**：每组从一张风景/花卉照片取色，横向叠 5 个色块，标注英文名及 **HEX / RGB / CMYK** 四套数值，可直接复制进 Figma、PPT 或 CSS。
- **暖黄系（油菜花）**：FLAX `#F8EC99` → GOLD `#DEB938` → OLIVINE `#A8B774` → CAL POLY GREEN `#2C4219` → TAUPE `#433A30`；阳光治愈，适合清新海报与品牌主色。
- **浅蓝系（玉兰花）**：BONE `#E0D7C7` → LION `#BE9F89` → LIGHT BLUE `#98C3C7` → MOONSTONE `#5399A0` → GUNMETAL `#1B2A31`；冷暖中性搭配，夏天微风感、偏高级冷静。
- **日落粉紫系**：WHEAT `#FCE5C3` → PEACH `#F7B596` → MELON `#EEA59E` → PAYNE'S GRAY `#626C8B` → DARK PURPLE `#402C39`；从暖肤到深紫渐变，适合浪漫叙事与摄影后期 LUT 参考。
- **紫绿撞色系（风铃草/蓝bell）**：WISTERIA `#BAACEB` → ULTRA VIOLET `#5F5AA5` → YELLOW GREEN `#B8D062` → AVOCADO `#5E891B` → PAKISTAN GREEN `#283B0A`；梦幻紫配黄绿，对比强但不刺眼。
- **夏日蓝绿系（蓝天白花）**：BABY POWDER `#F3F6F3` → JORDY BLUE `#9EBEED` → CHEFCHAOUEN BLUE `#4E90F5` → APPLE GREEN `#94C000` → DARK MOSS GREEN `#4B6B03`；高饱和蓝绿，适合 UI 主按钮与夏日促销视觉。
- **羽扇豆紫系**：COLUMBIA BLUE `#C5DCE1` → PUCE `#DD9AA9` → LILAC `#B094BC` → ROYAL PURPLE `#7B5AA5` → FEDERAL BLUE `#2A1C64`；粉紫到深藏青，温柔又带层次。
- **自然绿系（带水珠绿叶）**：SILVER `#C7C9C9` → ECRU `#C0B58E` → CAMBRIDGE BLUE `#93A989` → HUNTER GREEN `#386939` → DARK GREEN `#12341B`；环保、自然风、稳重有生机，适合作 sustainability 或户外品牌。
- **金色 orchard 系**：WHEAT `#F9E3B6` → SUNGLOW `#FBCE6B` → GOLDENROD `#D5A007` → AVOCADO `#6C8B08` → DRAB DARK BROWN `#2B2202`；暖黄到深棕，秋夏过渡或复古暖调排版均可套用。
- **少女粉系（波斯菊）**：LAVENDER BLUSH `#F4DFE6` → AMARANTH PINK `#E0A3BB` → AZURE `#D6E6E7` → CITRON `#C5CC82` → MOSS GREEN `#97A13B`；甜而不腻，穿搭与小红书封面 carousel 可直接当灵感板。

🌿 绿色系：很适合环保、自然风主题，稳重又有生机
🌸 粉色系：少女感拉满，甜而不腻
