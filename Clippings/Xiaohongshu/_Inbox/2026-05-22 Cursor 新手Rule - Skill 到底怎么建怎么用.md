# Cursor 新手Rule / Skill 到底怎么建怎么用

## 要点

## 正文

Cursor 新手必看。
最近好多人问我：
Cursor 里的 Rule、Skill、MDC 到底是什么？
怎么建？格式是什么？它们之间有什么关系？
	
今天就临时追一期讲这个规则的笔记，有什么不清楚的评论区或者群里可以留言，大家一起学习，一起进步。
	
新手避坑
❌ Rule 不要超过 300 行
❌ Skill 文件夹里必须叫 SKILL.md（大写）
❌ MDC 不要写废话，要具体、可执行
❌ 不要一个文件写所有规则，要拆分
	
总结
Rule = 规矩 → .mdc → .cursor/rules/
Skill = 能力 → .md → .cursor/skills/
