# 国内也能用ClaudeCode了？

> **@数字生命卡兹克** · [原文](http://xhslink.com/o/AfR2LdfMn8i)

## 要点

- **区分框架与模型**：Claude **模型**国内难直连，但 **Claude Code** 作为 Agent **框架**可用；接入国产模型（Gemini、Mimo、Kimi 等）体验仍好。
- **安装**：按网络条件在终端执行官方安装命令；Mac 需前置依赖、Windows 另需组件（见视频截图）。
- **接模型**：推荐 **CC Switch**；填 API Key 与模型名即可切换，无需手改一堆配置。
- **关键一步：CLAUDE.md**：开工前 Agent 会读的**项目规则**；约束先行，按模板改红色占位项，避免「厉害实习生没规矩乱干」。
- **适用**：Windows / Mac；教程与 Prompt 见置顶评论；本库 `0 工作流` 可对照自建规则。

## 内容纪要

### 产品关系：框架 ≠ 必须官方模型

一个 Agent 产品 = **框架** + **模型能力**。Claude 原生模型在国内受限，但 **Claude Code 框架本身并不被封**。因此可以把 Claude Code 接到 **Gemini 2.5、小米 Mimo V2.5 Pro、Kimi K2** 等国产模型，作者实测效果仍接近原生体验。

### 安装 Claude Code

在终端粘贴视频中的安装命令执行即可。注意：无「魔法」的 Mac 需先装指定依赖；Windows 需另装组件（具体命令见视频图示）。

### 用 CC Switch 接入模型

安装框架后，用 **CC Switch** 统一管理模型：Mac 终端执行两行命令；Windows 下载安装包。在 Claude 一栏点「+」，填入 **API Key** 与模型配置，其余自动完成；以后要换模型在工具里切换即可。启动 `claude` 后一路回车完成初始化，出现交互界面即表示接入成功（作者示例为 Gemini 2.5）。

### 真正重点：先写 CLAUDE.md（约束先行）

很多人装完就直接用，结果 Agent 常「干偏」——像招了厉害实习生却不讲规矩。  
**CLAUDE.md** 是 Agent **每次开工前会读**的规则文件。视频提供模板：按自己项目改**红色标记**部分，其余可让 Claude Code 写入仓库。作者原则：**约束先行**——规范定好后，用一两周 Agent 才会长成你要的样子。

### 与「小龙虾」等工具对比

博主定位为国内、免魔法、全平台（Win/Mac）的 Claude Code 上手教程；各阶段 Prompt 在置顶评论区。
