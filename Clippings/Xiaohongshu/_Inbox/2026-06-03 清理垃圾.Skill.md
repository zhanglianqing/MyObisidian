# 今天，我决定开源「清理垃圾.Skill」

> **@数字生命卡兹克** · [原文](https://www.xiaohongshu.com/discovery/item/6a1e6ebb00000000060217b7?source=webshare&xhsshare=pc_web&xsec_token=CBBkSaJWPhNFP9IMOZGDEKxvryJXijFe_TtLV0rwuCnLQ=&xsec_source=pc_share)

## 要点

- **起源**：受推上「Codex 只读扫描 Mac 可清 500G（含 116G `codex-tui.log`）」启发；作者用同款英文只读 prompt + 中文回答，发现约 **100G B 站离线**藏在深 `Containers` 路径，评估保守 **120G**、激进 **140G+** 可腾。
- **痛点**：CleanMyMac 年费约 40 刀/买断 120 刀，只标「用户缓存」大类，说不清 Chrome 里 Service Worker / IndexedDB / 扩展数据删了会否掉登录或离线功能；早期 Codex 报告也只列占用、建议模糊、**不能代删**。
- **产物**：开源 skill **`storage-analyzer`**（帖名「清理垃圾.Skill」），仓库 **[khazix-skills](https://github.com/KKKKhazix/khazix-skills)**；**Mac / Windows** 自动识别，不绑定单一 Agent 产品。
- **用法**：对 Agent 说「帮我看看存储」「磁盘满了」「看看谁占空间」或跑 **`/storage-analyzer`**；先授权 → **只读**全盘扫描 → 浏览器打开本地 **可折叠 HTML 报告**（例 `127.0.0.1:60210`），并落盘 `storage-report-latest.html` / `storage_analysis_latest.json`。
- **红黄绿**：**绿灯** = 可再生纯缓存/安装包残留（`uv`/`npm`/`brew` 缓存、Downloads 里 `.dmg`/`.pkg` 等），每项给路径、可复制命令、**移到废纸篓 / 直接删除**；**黄灯** = 含用户数据需你拍板（B 站离线约 **96.7G**、Chrome 配置、微信容器、`.platformio` 等）；**红灯** = 系统/在用应用/须正规卸载（重复 CleanMyMac、iMovie 等），只引导不自动删。
- **安全**：扫描阶段 **禁止写入**；任何清理须网页点按钮 + **浏览器二次确认**；默认先废纸篓可恢复；红灯提供「在访达打开」或网页说明，**不替你拖删**带守护进程的应用。
- **实测**：作者 MacBook Air 清后约 **182G 已用 / 311G 可用**（称清近 **120G**）；对比 CleanMyMac 扫半小时仅 **15.8G**「可清理」；同事 **Windows + Codex** 亦出 C 盘分级（桌面 ~158G、剪映 ~134G、下载 ~13G 等，缓存约 **32G** 可安全释放）。
- **观点**：Agent skill 比写死规则更透明（路径/大小/删后影响），可用大白话定制「找哪种垃圾」；作者视为「工具型软件变耗材、竞争对手是一条 prompt」的小样例。

## 正文

前段时间在推上刷到了一条帖子，有位老哥分享了他让Codex对他的MacBook做一次全面的只读存储分析。发现可以清出500G的空间，Codex还找到了一个116G大的codex-tui.log文件。。。
	
正好我当时这台MacBook Air陪了我快2年的时间，装了一堆乱七八糟的东西，我就想着也试一下。
结果，不扫都不知道，我电脑上竟然有快100个G的B站视频，我都懵了。而且还藏在一个相当深的Containers目录下面。
	
Codex最后给了一个判断，按这个清单清，保守能腾出120G，激进一点能到140G以上。
	
这就让我想到n年前，我找到的给MAC电脑清垃圾的软件。而且这玩意不是免费用的，正版一年近40刀，一次买断要120刀。当时刚毕业我根本买不起。而且甚至到了今天，清理Mac的垃圾，都没有一个很好用的产品。Windows生态也差不多。
	
但现在AI时代，好像，Agent就能直接干了。
本身你直接清理电脑垃圾也就是包装了一层UI，然后对我电脑底层进行扫描和操作，那我让Agent直接操作，感觉会更牛。
	
同时，原版prompt其实有个问题，它只是一个比较专业一点的只读文档，然后给你列了一个占用清单，又给了一些不太清楚的清理建议。
对没太熟悉系统的朋友，看完整份报告，其实还是会不太敢动手。
	
哪些能放心清，哪些得自己看一眼再判断一下，哪些绝对千万别碰，这些判断它没有帮你直观清晰地列出来。
而且他也没法帮你删东西。
	
所以就有了这篇文章，我想，直接干脆自己搓一个skill，来解决清理电脑垃圾的需求。大概烧了一些Token后，这个清理垃圾.skill，就顺利面世了，而且，Mac和Windows都能用。希望大家喜欢～
	
如果觉得有用的话，欢迎把它分享给你的朋友们一起看看，这对我们有特别大的帮助！
