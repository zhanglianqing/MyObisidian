## 怎么用

1. 打开上表对应文件夹，读其中的 `README.md`。
2. 把示例、prompt 复制给 Cursor / Codex，让它结合你的 vault 迁移。
3. 可选：把 [shared/AGENTS.md](shared/AGENTS.md) 合并进 vault 根（写入正式页面前须确认）。

第 2 篇骨架：

```text
项目资料留在项目内
每个项目有自己的 ResearchTrack
每条线抽出 1 个当前下一节点
工作台汇总当前推进视图
本周推进再拆成可执行任务
```

详细步骤 → [SETUP.md](./SETUP.md)

## 本包不含

- 个人项目笔记、真实审稿 active 页、简历材料
- 邮件 IMAP 凭证、剪藏 Cookie、远程 SSH 私钥
- 原始数据、真实路径、真实合作者信息
