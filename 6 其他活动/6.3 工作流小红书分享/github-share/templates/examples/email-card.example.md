# 邮件整理 · 摘要卡片示例（审稿邀请 · 脱敏）

> 整理模式下，AI 对 `_email_drop` 里每封邮件输出一张类似结构的卡片。确认后才写入 `10 杂志审稿/active/`。

---

## 卡片 · JOURNAL-26-xxxx 审稿邀请

| 字段 | 内容 |
|------|------|
| **分类** | `peer-review` → `10 杂志审稿/` |
| **action** | `required` |
| **deadline** | **2026-06-13**（编辑部；建议提交不晚于 2026-06-12） |
| **关键时间节点** | 邀稿 2026-05-20 |
| **要求清单** | Editorial Manager 提交审稿意见；用户名 `Reviewer-xxx`；附件 manuscript.pdf |
| **操作链接** | Agree: `https://…` · Decline: `https://…`（邮件原文链接，便于一键接/拒） |
| **建议路径** | 新建 `10 杂志审稿/active/JOURNAL-26-xxxx 简称/` |
| **本周关系** | 可选写入「同期项目-下一节点」：通读 + 撰写意见 ⏳ 2026-06-12 |

**建议操作**：确认后在 active 建文件夹 + 稿件笔记；更新 ReviewTrack（用户同意后）；删除 drop。

---

## 卡片 · 期刊订阅推送（skip 示例）

| 字段 | 内容 |
|------|------|
| **分类** | `skip` |
| **action** | `skip` |
| **deadline** | 无 |
| **建议路径** | 不建 active |
| **本周关系** | 无 |

**建议操作**：确认后删除 drop；不写入 10/11/12。
