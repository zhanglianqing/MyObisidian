# 迁移口令

## 先读示例，不改文件

```text
请先阅读 examples/00_ResearchTrack.example.md 和 AGENTS.md。
我想把当前 vault 改造成多项目 workflow。
请先不要改文件，先列出：
1. 哪些文件夹像正式项目；
2. 哪些项目需要 ResearchTrack；
3. 哪些页面适合作为“同期项目-下一节点”和“本周工作台”；
4. 你建议的迁移步骤；
5. 哪些写入动作需要我确认。
```

## 给单个项目建立 ResearchTrack

```text
请参考 examples/00_ResearchTrack.example.md，
为这个项目建立一个同结构的 ResearchTrack。

要求：
1. 保留当前焦点、资料入口、待办池、已完成、决策记录。
2. 不迁移原始数据，不复制敏感路径，只做入口索引。
3. 从这个项目中抽出一条“当前下一节点”。
4. 先给我预览草稿和建议节点，等我确认后再写入。
```

## 汇总下一节点

```text
请为这些项目建立“同期项目-下一节点”页面。
规则：
1. 每条项目线只保留一个 open 下一节点。
2. 下一节点要链接回对应 ResearchTrack。
3. 已完成节点勾选后，再写新的下一节点。
4. 这个页面用于工作台汇总，不写完整 todo list。
先列结构和示例，等我确认后再写入。
```

## 建本周工作台

```text
请建立“本周工作台”页面。
目标：
1. 汇总“同期项目-下一节点”里的当前节点。
2. 留出本周时间/空档视图。
3. 不把所有项目待办塞进工作台。
4. 需要执行的细则另放到“本周推进”页面。
先给我页面结构和示例内容，等我确认后再写入。
```
