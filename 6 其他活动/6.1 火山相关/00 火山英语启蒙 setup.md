## 一、背景与动机

**5/14**（[[关于火山的学习]]）：火山说不想去英语课，因为「都不会」。当作建立**正向循环**的契机——在家补**可理解听力**，不跟课堂输出硬扛。

**孩子**：4 岁半，香蕉妈妈 **启动阶段**（听力理解为主，不追认字/跟读/刷级）。

**阶段语言（双轴）**：庆爸 **前置积累**（~200 词 / 50 h → 300 词 / 60～80 h）+ 读物 **w-play 先行**（见 [[3-4岁常规路径2.0-与火山对照]]）。

---

## 二、原则摘记（香蕉妈妈 · 执行时对照）

| 原则 | 要点 |
|------|------|
| **听力先行** | 启动期只做「听+懂」；4～5 岁起步约半年～一年可压缩，重点是听懂小故事 |
| **听 ≠ 读** | 不把认字、拼读、分级跟读绑在同一套书上 |
| **可理解输入** | 画面/helpers 建理解；坚持共读比焦虑口语重要 |
| **勿只盯输出** | 不开口、不跟读正常；挫败感已靠 **兴趣+带读闭环** 缓解，仍不以输出驱动 |
| **不必读透才换** | 同表达多场景重复即可 |

**学龄前远景**：一年级时能按**认知**选英文读物（不必冲 KET / 口语无障碍）。

**常见误区**（详剪藏）：全英文对话才能启蒙、分级读透才晋级、只听不读却急着指读认词、只报课不家庭输入。

## 三、当前定案（2026-06-02）

### 3.1 在跑什么

| 项 | 定案 |
|----|------|
| **读物主线** | 仅 **w-play**（40 min/次，周中约 3 次，家长在场）；海尼曼/牛津/RAZ **不开** |
| **动画** | **小彼恩配套**：**w-play** + **古力系列** 动画/视频（早饭 + 无带读晚）；内容已够，与带读 **分开计时** |
| **网盘三季**（雅克迪/迪迪狗/动物王国） | **基本不推**（5 月试过后搁置；雅克迪卡/桌游可日后当玩具） |
| **无带读晚** | 默认周二、周四；**不做** w-play；App **只复习**已带读/已看过的单元 |
| **点读笔** | 游戏页「完成任务工具」，不当认字器 → 计划表 §六 |
| **复习/检测** | **亲子互动**（带读、贴纸/游戏、口语提示）；~~maskmysheet~~ 已试不采用 |

### 3.2 进度快照

| 项 | 状态 |
|----|------|
| w-play 带读 | **6 / 12**；回城后余 6 本约 **2 周** |
| 配套动画 | **w-play + 古力** 配套，每天主动看；杭州起 **音频能跟读** |
| 外婆家 ~2 周 | 只续看 **已熟悉单元** 配套动画 |
| 挫败感 | **w-play 已解决**；古力小超人 **5/27 不再抵触** |

### 3.3 w-play 之后（粗排期）

→ 详见 [[火山英语启蒙-资源与心愿单#四、阶段排队]]：**q-play** → **古力朋友 / 古力小超人** + 互动游戏书穿插 → 海尼曼 **按需**。前置书单跑完约 **4～5 个月**（~60～80 h 量级，对话中估）。

**加第二条读物**（海尼曼或牛津 L1 只听）：w-play 盒做完 + 仍愿听 + 裸听大致懂 + 家长有余力 → 见资源页 §四。

### 3.4 每周量级（自检）

| 类型 | 目标 |
|------|------|
| w-play 带读 | 3 × 40 min ≈ **2 h/周** |
| 配套动画 | 早饭 7 次 + 无带读晚 2 次 ≈ **1.5～2 h/周**（w-play + 古力） |
| **合计** | **~3.5～4 h/周** |

### 3.5 与线下课

家庭仍 **听→懂**；是否续课等听力补一段再与火山沟通。
