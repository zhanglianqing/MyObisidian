## §一、必备基本要求

| 要求                                     | 自为 / 难度                    | 需要什么支持                                 |
| -------------------------------------- | -------------------------- | -------------------------------------- |
| 政治立场、师德师风、关爱学生等（§1.1）                  | **可自为 · 易** — 日常履职         | —                                      |
| 任现职以来考核合格；近 3 年无学术道德/师德/严重教学事故等（§1.2）  | **可自为 · 易** — 日常履职         | 人事/科室出具或内部核对                           |
| 近 3 年本科评教非本单位后 20%（§1.3）               | **可自为 · 易** — 日常履职         | —                                      |
| 未满 35 岁须 ≥1 年辅导员/班主任等或支教等经历（§1.4）      | 中                          | 需要申请，并完成相应工作                           |
| **博士学位**（§1.5）                         | **已满足**                    | —                                      |
| **任中级满 5 年，或获博士任中级满 2 年**（§1.6）        | **已满足**                    | 与人事确认现职起算、中级认定、预计申报窗口                  |
| **主持国自然青年科学基金及以上 1 项**（§1.7②，硬门槛）      | **无国自然**                   |                                        |
| 院级继续教育 ≥10 次/年，A 类 >5（§1.8，2019 起）     | **可自为 · 易** — 按年参加并记台账     | —                                      |
| **第一/通讯作者教育教学研究论文 ≥1**（§1.9，2020 起硬门槛） | **可自为 · 中** — 可写，但需题材与发表周期 | **科室**：教改课题立项、课程建设纳入署名机制；与科研方法论 2.0 绑定 |

## §二、公共服务要求

> **组合规则**：第 1 条 **+** 第 2 / 3 / 4 中 **一条**。

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| **§2.1** 指导学术型社团，或担任双创/大创/互联网+/挑战杯等指导教师 | **待核实** — 2021 互联网+省金为参赛侧，**官方指导教师身份**待确认 | 科室认定**竞赛/大创指导教师**；或安排可计入的竞赛指导任务 |
| **§2.2** 班主任/学业导师/创新班导师/秘书/党工团等 | **难自为** — 岗位需单位安排 | **李老师/科室**：学业导师、创新班导师或科室公共服务岗 |
| **§2.3** 支教/挂职/援疆/援藏/援外/扶贫/义诊等 | **难自为** — 依赖派出机会 | 若有政策窗口可争取；非近期主路径 |
| **§2.4** 每年 ≥32 学时公共服务（监考、招生评审、外审、学科研讨等） | **可自为 · 易** — 日常可累积 | — |

## §三、教学要求（副教授必备 1、2、4）

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| **§3.1** 独立讲授本科及以上课程 ≥2 门（含 1 门本科，该课 ≥32 学时/年） | **难自为** — 科研方法论在谈但未稳定落地；**门数/学时待核实** | **李老师/科室**：教学大框架（研究中心/工作组）；认定**课程牵头**；**减临床排班**换授课工时 |
| **§3.2** 平均每年周均学时 ≥4 | **难自为** — 与 §3.1 联动，临床排班占满则难达标 | 同上：**工时置换** |
| **§3.4** 指导本科毕设或毕业实习 ≥2 届 | **可自为 · 中** — 有人名额就能做，但需**连续承接** | **科室/教务**：稳定分配毕设/实习指导名额（≥2 届） |

## §四、科研业绩要求

> **组合规则**：**1 / 2 / 3 中一条**，**或** **4 / 5 / 6 / 7 中两条**。  
> **初判主攻**：路径 B → **§4.5 + §4.7**；§1.7 国自然为申报前置，与 §4.2 同源。

### 路径 A（三选一）

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| **§4.1** A- 级及以上论文 ≥1；**或** B 级及以上 ≥4 | **待核实** — 12 篇一作/共一，**SCU 分级未对照** | 科管/人事提供最新**期刊分级表**；对照 [[张帘青-论文-刊物指标]] |
| **§4.2** 国自然面上+；或国家级项目 ≥60 万；或重大纵向 ≥200 万（前 2） | **难自为** — 与 §1.7 同源，**无国自然** | 同 §1.7：方向、团队、预评审 |
| **§4.3** 省部级及以上科技奖/教学成果奖（指定排名） | **难自为** — 短期不可规划 | 非近期主路径 |

### 路径 B（四选二 · 初判 §4.5 + §4.7）

| 要求 | 自为 / 难度 | 需要什么支持 |
|------|------------|-------------|
| **§4.4** 重大纵向 ≥200 万（前 3）/ 横向 ≥300 万 / 负责人累计 ≥100 万 | **难自为** — 负责人累计约 **36 万**量级 | **科室大项目**参与排名；或继续拿纵向（周期长） |
| **§4.5** B 级及以上 ≥2；或 D 级及以上 ≥4 且 C 级及以上 ≥2 | **待核实 → 可自为 · 中~易** — 论文存量可能够，差分级确认 | 期刊分级表；不够则规划 1–2 篇 targeted 投稿 |
| **§4.6** 省部级奖 / 成果转化 ≥30 万 / 国际国标 / 行业标 / 指南执笔等 | **难自为** | 非近期主路径 |
| **§4.7** 省级教学成果奖；或马工程/国家级规划教材主编副主编；或参编规划教材 ≥5 万字；或精品课/一流课程/品牌课主讲（指定排名） | **可自为 · 难** — 有参编基础，但**身份/排名需平台** | **李老师/科室**：科研方法论 2.0 → **一流课程/规划教材/教学成果奖**打包；教指委/教务认定 |
