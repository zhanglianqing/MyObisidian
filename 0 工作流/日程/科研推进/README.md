# 科研推进（周任务层）

本文件夹存放**周层科研任务细则**（带 `⏳`），供 Tasks 总控抓取。与 `1 主线项目` 的实质内容（论文、数据、Research Track）分离。

| 文件 | 用途 |
|------|------|
| [[本周科研推进]] | 当周可勾选任务（`week_of` = 当周一） |
| `YYYY-MM-DD 科研推进.md` | 顺延 / 预排的下周及以后任务 |

**维护顺序**：[[本周工作台]] §一 → [[同期项目-下一节点]] → [[本周科研推进]]。说明见 [[0 工作流/workflows/3.4 Workflow ：长周期项目与每日规划（试点）#定稿摘要（调用入口）]]。
