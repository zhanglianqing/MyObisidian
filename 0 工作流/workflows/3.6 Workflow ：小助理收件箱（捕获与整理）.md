## 一、PC 捕获（Cursor Agent）

| 步骤 | 你做 | 系统 |
|------|------|------|
| 1 | **Agent 模式**发 `小助理：` + 一条或多条 | |
| 2 | | 按 `assistant-inbox.mdc` 追加收件箱 |
| 3 | | 回复列新增项 +「已记入，未执行」；若适合同步周控台，附建议变更并请确认 |
| 4 | 确认后（可选） | 写入 [[本周工作台]] / [[同期项目-下一节点]] / [[本周科研推进]] |

**行格式：**

```markdown
- [ ] 2026-05-24 15:30 | 待办 | 明天交伦理材料
```

**禁止（捕获时）**：跑脚本、改代码、展开方案、**擅自**写工作台 / 下一节点 / 科研推进（须先请用户确认）。

## 二、手机捕获（iOS 快捷指令 · 无 AI）

复用 [[0 工作流/工具箱/归档/Ongoing_小红书手机剪藏-进度纪要-2026-05-18]] 的坚果云 WebDAV 经验；**推荐 WebDAV PUT 单文件**（比 Files 扩展选 Nutstore 子目录更稳）。

### 2.1 drop 文件格式

见 [[0 工作流/_assistant_drop/README]]。快捷指令生成：

```markdown
---
type: todo
captured_at: 2026-05-24T15:30
source: ios-shortcut
---

明天交伦理材料
```

`type`（英文码）：`todo` | `idea` | `notice` | `misc`（缺省 → misc）。对应收件箱四区顺序。

### 2.2 快捷指令「小助理捕获」步骤

1. **输入**：剪贴板 / 听写 / 要求输入  
2. **选类型**（可选）：从菜单选 todo / idea / notice / misc（对应待办 / 想法 / 通知 / 杂项）  
3. **文本**：拼 frontmatter + 正文（见上）  
4. **文件名**：`yyyyMMdd-HHmmss.md`  
5. **WebDAV 上传**  
   - URL：`https://dav.jianguoyun.com/dav/MyObisidian/0 工作流/_assistant_drop/<文件名>`  
   - 方法：**PUT**  
   - 认证：坚果云账号 + **应用密码**（账户安全 → 第三方应用管理）  
   - 请求体：上一步拼好的 markdown  
6. **通知**：「已入队；PC 开 Cursor 后自动合并」

> **路径说明**：`MyObisidian` 为 vault 在坚果云 WebDAV 下的文件夹名；若你本机路径不同，在坚果云 WebDAV 根目录下找到 vault 名后替换。

### 2.3 备选：坚果云 App 存文件

若 iOS「文件」能选到 `_assistant_drop`，可用「存储文件」直接写入；此前 xhs 队列在 Files 扩展里选子目录不稳定，**以 WebDAV 为主**。

### 2.4 与小红书队列对比

| | 小红书 `_xhs_queue` | 小助理 `_assistant_drop` |
|--|--|--|
| PC 处理 | 轮询 + `clip_xhs_auto`（重） | sessionStart 合并（轻） |
| 需 Cookie/转写 | 是 | 否 |
| Cursor 角色 | 归类要点 | 仅「小助理整理」时介入 |

## 四、Hooks 与手动合并

### 4.1 sessionStart Hook

打开本 vault 工程时，`.cursor/hooks.json` 调用 `merge-assistant-drop.ps1` → `Merge-AssistantDrop.ps1`：

- 成功 → 行写入收件箱，drop 移 `_done/`  
- 失败 → drop 移 `_failed/` + `.log`  
- **fail open**：合并失败不阻断 Cursor 启动  

排查：Cursor **Hooks** 输出通道；应见 `Merge-AssistantDrop: merged=N failed=M`。

### 4.2 手动合并

```powershell
cd "c:\Users\41516\Nutstore\1\MyObisidian\0 工作流\scripts"
.\Merge-AssistantDrop.ps1
```

Hook 未触发或想立即入库时用。

### 4.3 局限

- 只有**打开 Cursor 本工程**时才会自动合并 drop  
- 若要不开 Cursor 也入库：手动跑脚本，或后续 Windows 计划任务轮询（可选进阶，本次未做）

### 4.4 故障

| 现象 | 处理 |
|------|------|
| drop 一直不消失 | 手动跑 `Merge-AssistantDrop.ps1`；查 `_failed/*.log` |
| 行进了错区 | 检查 drop frontmatter `type` |
| Hook 无输出 | 重启 Cursor；确认 `.cursor/hooks.json` 存在 |
