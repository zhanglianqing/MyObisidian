# 3.8 文献库组织架构

> **定稿**：2026-06-04（`_drafts/` · 内化定稿仅在 `literature/` · 项目只链 citekey）  
> **归属**：[[3.0 Workflow ：AI 原生科研工作流架构]] · 操作细节见 [[3.1 Workflow ：Zotero+Obsidian 文献由进到出全流程]]  
> **Obsidian 落地**：[[7 可复用知识库/literature/README]]  
> **范围**：文献存放、内化笔记、专题外置 AI；**不含** talk / 单篇幻灯。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **单一权威** | PDF 与元数据只在 **Zotero + 坚果云链接附件**；vault 内不长期堆 PDF 副本。 |
| **Collection 三夹** | Zotero 仅 `Cornerstone` / `My Papers` / `Everything`；**不打 Zotero tag**。 |
| **逻辑分面** | 多 slot / 多 project 写在 S1 的 `slots`、`projects` 与正文，一篇一 citekey。 |
| **内化与原文分离** | 日常写作用 **S1 定稿** + `[@citekey]`；PDF 仅在需要时打开或复制到专题包。 |
| **一篇一稿** | 内化定稿只在 `literature/{citekey}.md`；多 project 复用靠 `slots` / 「引用场景」，**不**在项目下复制全文。 |
| **草稿与定稿分离** | Agent 初稿进 `_drafts/`；你认可后晋升 S1；项目 track 只链 citekey。 |
| **AI 工具分工** | 默认 **Cursor + Copilot + Zotero LLM**；Gemini / NotebookLM 用 **临时专题包**，不维持全库文件夹镜像。 |
| **印象笔记** | 仅作迁移过渡（原料）；`05_文献阅读/` 晋升至 `_drafts/` 或 S1，**不**迁入 project 文献库。验收后删除 `印象笔记存档/`。 |
| **语义在 Obsidian** | 检索与归属靠 S1 + bib + citekey；不在 Zotero 内筛文献。 |

## 3. Zotero（S0）

| Collection | 用途 | Attanger 子目录 |
|------------|------|-----------------|
| `Cornerstone` | 全线反复引用的基石 | `literature/Cornerstone/` |
| `My Papers` | 本人已发表 / 投稿中 | `literature/My Papers/` |
| `Everything` | 默认新入库、备查 | `literature/Everything/` |

- 新文献 → `Everything`；基石 + 已有 S1 → `Cornerstone`；自己的文章 → `My Papers`。每篇**只属于一个** Collection。  
- 改稿批次可用**临时夹**（如 `RTNF-manuscript`），用完可删。  
- **禁止**按项目建 Collection；**不使用 Zotero tag**（slot / 项目 / 阅读进度写在 Obsidian S1）。  
- BBT citekey + `Zotero-lib/My Library.bib` 保持更新；Attanger `{{collection}}` 见 [[3.1 Workflow ：Zotero+Obsidian 文献由进到出全流程]] §1.2。

## 4. Obsidian：草稿 → S1 定稿 → 项目只链

落地说明：[[7 可复用知识库/literature/README]]。

### 4.1 草稿 `_drafts/`（晋升前）

- **路径**：`literature/_drafts/{citekey}.md`（文件名仍 = BBT citekey）。  
- **何时写**：你向 Agent 要「先抽一版」；或从印象笔记 `05_文献阅读/`、原料整理，**尚未认可**为内化定稿。  
- **谁写**：默认 Agent；模板 [[7 可复用知识库/literature/_templates/literature-draft]]，`status: draft`，`source` 链原料。  
- **晋升**：你审改四段 → 写入或合并到 `literature/{citekey}.md` → 删除/归档 `_drafts/` 同名文件。  
- **禁止**：在未确认时覆盖已有 S1 定稿；禁止在 `_drafts/` 下按项目分子目录。

### 4.2 S1 定稿（唯一内化正文）

- **路径**：`literature/{citekey}.md`。  
- **可选前缀**：`LR_` 仅用于文件管理器排序，**不**建 `1a-2a/`、`3c/` 等项目子目录。  
- **何时建**：已进主稿引用、改稿会反复 @、或列入 `MOC-*`；其余可只在 Zotero 保留条目。  
- **正文结构**（模板 [[7 可复用知识库/literature/_templates/literature-note]]）：
  1. One-liner  
  2. 框架 / 方法要点  
  3. 与我工作的接口（slot、分割策略等）  
  4. 引用场景（**可多项目**列在同一文件）  
  5. 来源（可选：链 `_drafts/`、印象笔记原文）  
- **frontmatter**：`slots`、`projects`；`zotero_tags` 可不写。

### 4.3 项目侧（只链，不复制）

- 在 `00_ResearchTrack`、`文献-阅读队列.md`、主稿中：`[[citekey]]` / `[@citekey]`。  
- **勿**在 `1 主线项目/前期产出/<项目>/literature/` 养第二套内化正文。  
- **印象笔记归档**（[[3.5]] Step 6）：实验过程、`05_文献阅读/` HTML 等为**原料**；文献晋升目标是 `_drafts/` 或 S1，不是 project 文献库。  
- **迁移对照表**（引文/内化进度、印象笔记 triage）：`7 可复用知识库/_migration/`（**过渡**，验收后删除，见 [[7 可复用知识库/_migration/README]]）。

**闭环**：原料/bib → `_drafts/` → 你审改 → `{citekey}.md` 定稿 → 项目只链 citekey；改稿 @ 定稿 + bib。

## 5. S2：主题 MOC（虚拟分类）

- 目录：`7 可复用知识库/literature/_views/`  
- 文件示例：`MOC-全局基石.md`、`MOC-海马组织维度.md`、`MOC-疗效预测.md`  
- 内容为 **链接列表 + 一两句说明**，只链 **S1 定稿** `[[citekey]]`；`_drafts/` 未晋升前不入 MOC。  
- 勿粘贴 PDF 摘要全文；细节在 `../{citekey}.md`。  
- 新增：S1 定稿后，在 MOC 表加一行 `[[citekey]]`。

## 6. 工具分工

| 场景 | 首选 | 材料 |
|------|------|------|
| 从原料抽内化草稿 | Cursor | `_drafts/`、印象笔记原料、`My Library.bib` |

## 7. 专题外置 AI（`_ai_sessions`）

详见 [[0 工作流/工具箱/ai专题/README]]。

**要点**

- 仅在专题深读时，将选定 PDF **复制**到 `0 工作流/工具箱/ai专题/<topic>-<YYYYMMDD>/`。  
- 用毕 **整夹删除** 或移出 vault 冷备份；**禁止**回写为第二套 Zotero Collection。  
- 若某专题 **连续数周** 使用 NotebookLM，可在 Google Drive 另建 `NotebookLM-drop/<topic>/`（按需同步），仍不是坚果云 canonical 库的一部分。  
- 生成方式：按 citekey / 清单手动复制 PDF。

## 8. 硬规则（检查清单）

- [ ] 每篇文献在 Zotero 中 **只属于一个** Collection（Cornerstone / My Papers / Everything）。  
- [ ] PDF 不在 `1 主线项目/` 下长期存放。  
- [ ] **内化定稿**只在 `literature/{citekey}.md`（平面）；**草稿**只在 `literature/_drafts/`。  
- [ ] 项目只 `[[citekey]]` / `[@citekey]`，**不**复制内化正文到 project `literature/`。  
- [ ] 外置 AI 只用 `ai专题/`（或 Drive 的 `NotebookLM-drop/`）临时副本。  
- [ ] 印象笔记迁移完成后删除 `印象笔记存档/`。  
- [ ] 不使用 Zotero tag；语义在 S1 `slots` / `projects` + 正文。
