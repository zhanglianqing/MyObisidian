## 1.3双机同步（Literature + 坚果云）
 **条目/笔记**：同一 Zotero 账号，`同步` 中开启自动同步与全文内容
 **PDF**：由 **坚果云** 同步 `literature` 根目录；每台机在 `首选项 → 高级 → 文件和文件夹` 将 **链接附件的根目录** 指到本机坚果云下的同一 `literature` 根，且与 Attanger **靶路径**一致（笔记本盘符/路径不同属正常，各自改成实际路径）。
 - **盘符/路径不一致**：提示找不到附件且路径指向另一台机器盘符时，在本机将 **链接附件根目录** 与 **Attanger 靶路径** 一并改为本机实际的 `literature` 根路径，并确认坚果云已把对应 PDF 同步到该目录。
 - **主力机排障（已验证）**：根目录留空 → 链接 PDF 报「找不到文件」；在 `首选项 → 高级 → 文件和文件夹` 将 **链接附件的根目录** 设为与 Attanger 相同的 `literature` 根（即各 `{{collection}}` 文件夹的上一级）后恢复。
    * #### Zotero「同步」页（附件）
	    - **个人文库**：关闭「用 Zotero 同步附件」——链接 PDF 不走 Zotero 存储，文件靠坚果云（或你指定的其他同步目录）。
	    - **群组文库**：不用群组 PDF 时可关；协作群组若依赖 Zotero 托管附件则保留。
    * #### Link 与网盘（概念）
	    - **Link**：附件为磁盘路径链接，不占 Zotero 内置附件存储。
	    - **Link + 坚果云**：靶路径必须在 **坚果云正在同步的目录**；否则只是本地链接，不会跟到另一台电脑。**勿**与 Google Drive 对同一文件夹长期双客户端实时抢写；Drive 若保留，用 [[3.0 Workflow ：AI 原生科研工作流架构]] 中的「按需暂停」策略即可。

## 1.4 Obsidian 端
**Citations 插件**：用于在笔记中快速插入引用（依赖 Zotero **Better BibTeX** 导出的 `.bib`）。
- **文献库路径**：填 **相对 vault 根目录**，如 `Zotero-lib/My Library.bib`（`.bib` 放在仓库内随同步；**勿**填 `E:\...` 等绝对路径，否则 Obsidian 同步插件设置后另一台路径无效）。**Citation database format** 与 Zotero 导出一致：Better BibTeX → **BibTeX**；Better BibLaTeX → **BibLaTeX**。
-  **双机：BBT 自动写入 `.bib`（每台 Zotero 各配一次）**
	- BBT 的自动导出**不会**随 Obsidian 同步；**每台电脑**在 Zotero 里：`文件 → 导出文献库` → 格式选 **Better BibTeX / Better BibLaTeX** → 保存到 **本机** vault 下的 `Zotero-lib\My Library.bib` → 勾选 **Keep updated / 保持更新**。	
- **插入引用**：该插件**没有**输入 `@` 自动弹出列表；使用命令 **Insert Markdown citation**（ **Insert Markdown citation** 绑定 **`Ctrl+Shift+I）。

## 三、 Markdown → Word（定稿与引文）

*   **复制 + Zotero（Word 插件）**：正文贴进 Word 后逐条「插入引用」；**参考文献格式由 Zotero + CSL 控制**，可刷新域。Obsidian 里 `[@citekey]` 可作占位。
*   **Pandoc**：一条命令由 `.md` 生成带参考文献的 `.docx`；正文 `[@citekey]` 与 `My Library.bib` 一致即可。**导出为普通文字**，非 Zotero 域；需国标等体例时再加 `--csl` 指向 [Zotero Styles](https://www.zotero.org/styles) 下载的 `.csl`。

### 3.3 Word 参考模板（下次：手搓 `reference.docx`）

**2026-05-25 结论**：从网上下载的 Pandoc 模板（Achuan / book 等）以及从样例 Word 自动抽取样式，效果均不理想；**定稿版式应在 Word 里手工做好一份 `reference.docx`**，再交给 Pandoc 套用。

**手搓步骤（备忘）**：

1. 生成空壳：`pandoc -o reference.docx --print-default-data-file=reference.docx`
2. 用 Word 打开，在「样式」窗格中按单位/个人习惯改：**标题 1–6、正文 / Body Text、First Paragraph、列表、表格、Block Text（引用）** 等（改样式定义，不是只改当前段落）
3. 存到 vault，例如 `0 工作流/工具箱/模板/pandoc/reference.docx`（该目录仅保留此文件；第三方 skill 包见 `_templates/pandoc_docx_template/`）
4. 导出时指定：`pandoc input.md -o output.docx --reference-doc="…/_templates/pandoc/reference.docx" --wrap=none`（**勿**在 PowerShell 里 `pandoc … | pandoc …`，会 UTF-8 乱码）

**Obsidian Enhancing Export**：`Word (.docx)` 自定义参数追加 `--reference-doc "…/reference.docx"`。

**仍须接受**：`[[wikilink]]`、`====高亮====` 等 Obsidian 语法不会自动变成 Word 域/高亮；定稿前在 md 中改为普通链接/加粗，或导出后在 Word 微调。
