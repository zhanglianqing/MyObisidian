# 基金申报

> 院内/校.ts 等**主动申报**（非期刊投稿、非审稿）。任务总览 → [[00_FundTrack]]；下一节点 → [[同期项目-下一节点#12 · 基金申报]]。

## 目录

| 路径 | 用途 |
|------|------|
| `active/` | 进行中申报 |
| `archive/` | 已提交或已过期 |

每则申报一个子文件夹；文件夹名含 **截止日期** 或 **基金简称**，便于检索。

## 与相邻目录区分

| | `10 杂志审稿` | `11 投稿征召` | `12 基金申报`（本目录） |
|--|---------------|---------------|-------------------------|
| 方向 | 审别人稿 | 会议/专栏投稿 | 基金/课题申请书 |
| 典型截止 | 审稿意见 due | 全文/摘要 due | 申请书纸质+电子 due |

## 清理

`archive/` 中已提交超过 **12 个月** 且无 revisit 价值 → 可删，保留 `00_FundTrack` 一行摘要。
