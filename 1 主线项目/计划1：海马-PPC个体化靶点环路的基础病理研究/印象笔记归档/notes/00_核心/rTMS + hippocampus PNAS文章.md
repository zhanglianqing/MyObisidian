# rTMS + hippocampus PNAS文章

#ToDo

  1. 参考TMS方案设计




  


该研究使用 fMRI-引导的经颅磁刺激 (cTBS) 来暂时性地干扰海马体的活动，并观察了这种干扰对参与者在未来想象和创造性思维任务中的表现的影响。研究发现，对海马体进行 cTBS 导致其活动减少，并且这种减少与参与者在未来想象和创造性思维任务中表现下降相关。具体而言，研究人员发现，与对顶点进行 cTBS 相比，对左角回进行 cTBS 减少了参与者在未来想象任务中产生的情节细节数量，并且也减少了他们在创造性思维任务中产生的创意数量。此外，fMRI 分析表明，与顶点相比，对左角回进行 cTBS 后，海马体在情节模拟和创造性思维任务期间的活动显着降低，而在非情节控制任务期间则没有降低。这些发现表明，海马体在情节模拟和创造性思维中发挥着因果作用，并且是这些认知功能的关键脑区。

  


  


<https://www.pnas.org/doi/abs/10.1073/pnas.2003535117>

这项研究表明，海马体及其网络对发散思维至关重要，并为未来探索海马体在创造性认知中的作用提供了新的方向。 

  


Key Takeaways

  1. 海马体传统上被认为与记忆有关，但近年来其功能被扩展到语言、同理心、问题解决、决策和一些创造性认知形式。

     1. First, there is now abundant evidence that HC is involved not only in episodic memory but also in implicit memory and working memory ([1](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r1)). As a result, many researchers today think that HC is not a key region of a memory system but a component that mediates a specific cognitive operation, which can be recruited by tasks traditionally associated with different memory systems if the tasks require that specific operation ([1](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r1), [2](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r2)). Although the nature of this operation is a topic of active research, a popular hypothesis is that the main function of HC is to associate different kinds of information ([3](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r3)). Of course, no brain region can support a cognitive task by itself; a region must team up with other brain areas, and HC often collaborates with the functionally and structurally connected angular gyrus (AG) ([4](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r4)).

     2. A second important development in our conceptualization of HC function was brought by evidence that HC—in collaboration with AG and a subset of default network regions known as the core network—mediates not only remembering past events but also imagining future events ([5](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r5)). This second expansion of HC functions is still within the memory domain, because imagining future events consists mostly in recombining fragments from memories of the past ([6](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r6)).

     3. In contrast, the third extension of HC’s “job description” has been beyond the memory domain, into territories such as language, empathy, problem-solving, decision-making, and some forms of creative cognition ([1](https://www.pnas.org/doi/full/10.1073/pnas.2008601117#core-r1)).

  2. 这项研究使用经颅磁刺激 (rTMS) 技术来干扰海马体及其网络的功能，发现海马体的功能障碍会损害未来的事件想象和发散思维。

  3. rTMS 的效果可以扩展到其他脑区，包括对侧半球，并触发补偿性网络反应。

  4. 研究结果表明，海马体相关过程不仅参与发散思维，在一定程度上也是必要的。

  5. 这项研究为未来研究海马体、角回和其他核心网络区域在创造性认知中的作用提供了新的方向。

  * 这个文章的实验是怎么设计的？




这篇文章采用了一种三阶段的实验设计，旨在评估抑制性连续theta爆发刺激（cTBS）对海马体脑网络在情景模拟和发散性思维期间的影响。

  


     1. 第一阶段，参与者仅进行fMRI扫描，完成三个任务：情景模拟、发散性思维和非情景控制任务，以及resting和T1扫描。

        1. two task runs alternating between episodic simulation, divergent thinking, and nonepisodic control tasks; 每个任务中，参与者都会看到一个物体词，并根据不同的指令进行相应的任务：情景模拟任务要求想象与物体相关的未来事件；发散性思维任务要求生成物体的创意用途；非情景控制任务要求生成与物体相关的句子和定义。

        2. a resting-state scan

        3. an anatomic scan (in that order).

     2. 第二阶段和第三阶段则涉及cTBS，与第一阶段相似，但没有进行解剖扫描。 在进入扫描仪之前，参与者会接受cTBS，分别针对控制部位（顶点）或角回目标区域。 角回目标区域是根据第一阶段的休息状态功能连接分析确定的，该分析以左前海马体为种子，并与情景记忆、模拟和发散性思维相关联。 扫描结束后，参与者会接受一个事后访谈，询问他们对每个扫描提示的想法。

     3. cTBS与resting state fmri间隔时间是多久？

        1. cTBS 与 resting state fMRI 之间间隔大约 22 到 25 分钟。 文章指出，在 cTBS 结束后，参与者被放置到 fMRI 扫描仪中，功能性和静息态扫描分别在 cTBS 结束后的 5 到 7 分钟和 22 到 25 分钟开始。

     4. cTBS的具体参数？

        1. cTBS 协议由 50Hz 三联脉冲（三个单脉冲间隔 20msec）组成，以 5Hz 的频率（每 200msec）重复 40 秒（或 600 个脉冲），使用参考文献 Neuron. 45, 201–206 (2005) 中的参数。该 TMS 协议被认为是抑制性的，并且会损害性能。 此假设基于先前研究表明 cTBS 会降低皮层兴奋性 、单变量 fMRI 活动 ，并且已被证明会破坏情节记忆期间的 和类似于本研究中使用的自传体记忆任务中的行为表现。 cTBS 强度由参与者特异性运动阈值确定。

        1. stimulation of the human motor cortex. Neuron. 45, 201–206 (2005)

        2. stimulation of the human motor cortex. Neuron. 45, 201–206 (2005)




  


cTBS部位（顶点或角回）的顺序在参与者之间是平衡的，不同的物体词在每个阶段都会使用。 实验结果只比较了顶点和角回cTBS阶段，以控制任务熟悉度和非特异性cTBS效应。
