## Step 4：维护本周排班与科研空档（30～45 min）

**`[[本周工作台]]`**（`0 工作流/`）= **周层**：§一 带娃/科研时段（对照 Full Calendar）；§二 同期各线下一节点。  
**`[[本周科研推进]]`** = **本周任务层**（带 `⏳`，供 Tasks 总控）。  
**`[[00 工作系统3.0：海马+抑郁症+认知损伤的机制及诊疗]]`** = 主线科研 track（**本 Step 不改写**）。

在工作台至少填：

1. **本周排班**（医院）  
2. **会议与固定日程**  
3. **火山时间**（带读格子 + 周末活动）  
4. **科研可用时段**（由前三项反推，并链到本周科研推进）

**产出物**：一眼看到这周**哪天能坐科研**；任务不在工作台堆。

## Step 7：任务写进 track（与 Tasks 兼容）（15 min）

在 `[[本周科研推进]]` 里，把 **Step 1～6 里尚未勾选** 的项，改成带日期的任务行（便于总控「下周计划」汇总），例如：

```markdown
### 待办
- [ ] Step 4：工作台排班表 + 本周科研推进 ⏳ 2026-05-19 🔼
- [ ] Step 6：Zotero 分组 + Obsidian 精读路径试跑一篇 ⏳ 2026-05-20
```

把 `⏳` 换成你下周真实日期；硬截止用 `📅`。

**产出物**：总控里能看到主线 set up 进度，而不只在 Initialize 里打勾。

## Step 8：最小可交付（MVP，60～90 min）

**只做一件**，做完即视为「set up 有科学产出，不是纯整理」：

- [ ] **选项 1**：一页「**当前科学问题**」（背景 5 行 + 未知 5 行 + 本周要澄清什么 5 行）  
- [ ] **选项 2**：一张「**数据 / 文献清单表头**」（列名 + 谁填 + 更新频率）  
- [ ] **选项 3**：「**分析/综述流程图**」手绘拍照或 Excalidraw 均可，链进 `[[本周科研推进]]`

在 `[[本周科研推进]]` 里 **链接到该 MVP 笔记或章节**。

**产出物**：下周任何人（包括未来的你）打开 track，能立刻看到「科学上推进了哪一格」。

---

## Step 9：收束（15 min）

- [ ] 在 `[[本周科研推进]]` 顶部加一行 **「本周 set up 已完成于：____」**（日期）。  
- [ ] 把 Initialize 里你已照做的步骤，**不必**全部保留勾选；以后新项目可复制本页再跑一轮。  
- [ ] 日历或总控里看一眼：**再下一周**的第一条推进任务是否已有一条带 `⏳`（避免 set up 周结束后真空）。

**产出物**：主线进入「可日常推进」状态，而不是停在整理完毕。
